# learningPlaywrightBatch

This repository contains sample JavaScript and Java files for learning and experimenting with Playwright and related development workflows.

## Contents

- `chapter1/` - sample JavaScript files, including `basic01.js` and `test2.js`
- `src/sample/` - sample Java source file
- `drivers/` - driver binaries (for local browser automation)
- `package.json` - project metadata and dependencies
- `.gitignore` - files and folders excluded from Git

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run sample JavaScript files with Node.js:
   ```bash
   node chapter1/basic01.js
   ```
